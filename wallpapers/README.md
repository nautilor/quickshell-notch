# Bundled wallpapers

One wallpaper per colour scheme: `wallpapers/<scheme id>.jpg`. Picking a scheme in Settings applies it
(Settings → Wallpaper → "Wallpaper follows colour scheme"). Picking a wallpaper by hand makes it custom and
schemes stop changing it until the toggle is switched again. A new scheme only needs a matching `<id>.jpg`.

Collected from community wallpaper repos (r/unixporn and its Discord, mostly) and matched to each palette by colour:
krishna4a6av/Wallpapers, michaelScopic/Wallpapers, Ahmosys/nordpapers, Unsplash (everforest, bamboo, edge, moonfly, sonokai, one-dark, vscode-dark; Unsplash License), plus a few from the author's own collection.
Artwork belongs to the original artists.
